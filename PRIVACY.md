# SysPulse Privacy Policy

Last updated: May 25, 2026

SysPulse is built to monitor servers that you add yourself. The app stores server profile metadata locally on your device and keeps passwords and private keys in the iOS Keychain.

## Data Stored By The App

- Server profile metadata such as name, host, port, username, tags, icon and color.
- SSH credentials in the iOS Keychain.
- Monitoring snapshots, terminal history, SFTP file metadata and app settings on your device.
- Optional encrypted profile export files only when you explicitly create and share them.

## iCloud Sync

If you enable iCloud sync, SysPulse syncs server profile metadata through your private iCloud account using CloudKit. Passwords and private keys are not included in the synced profile snapshot.

## Purchases

Purchases and subscriptions are handled by Apple App Store and StoreKit. SysPulse stores the resulting entitlement state locally so the app can unlock Pro features.

## Diagnostics

SysPulse does not run a third-party analytics SDK. GitHub Actions artifacts and TestFlight diagnostics may be generated by Apple or GitHub during development and distribution.
