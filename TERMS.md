# SysPulse Terms

Last updated: May 25, 2026

SysPulse is provided as a server monitoring, SSH terminal and SFTP file management tool. You are responsible for the servers, credentials and commands you use with the app.

## Use Of The App

- Only connect to servers you own or are authorized to administer.
- Review commands before running them over SSH.
- Keep your device, Apple ID and server credentials secure.
- Test destructive commands carefully before using them on production systems.

## Pro Features

Pro features may be unlocked through StoreKit purchases or subscriptions handled by Apple App Store. Subscription management, renewal and cancellation are controlled by Apple.

## Availability

Server monitoring, SSH, SFTP, iCloud sync and notifications depend on network availability, server configuration, Apple services and the permissions enabled for the app.
